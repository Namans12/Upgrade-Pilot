  1. Run tests on the old version to prove a green baseline.
  2. Bump the dependency; the same tests now break.
  3. Tavily reads the migration guide, Nemotron Lightning condenses it.
  4. Nemotron Super repairs with tools, then we verify with the unchanged tests.
